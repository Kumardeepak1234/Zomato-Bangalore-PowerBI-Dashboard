# 🍽️ Zomato Bangalore Restaurants Analysis - Power BI Dashboard

## 📌 Project Overview
An interactive Power BI dashboard analyzing over 8,700+ unique restaurants across Bangalore to uncover insights into customer ratings, dining costs, popular restaurant types, and online delivery trends.

## 🛠️ Tools & Techniques Used
* **Power BI Desktop:** Data Modeling, DAX Measures, Interactive Visualizations, and Dynamic Slicers.
* **Power Query (ETL):** Data cleaning, handling missing/null values, standardizing rating formats (`/5` and `NEW`), and data type conversions.

## 📊 Key Insights
* **Total Unique Restaurants:** 8.74K across major Bangalore zones.
* **Average Rating:** 3.70/5 across listed establishments.
* **Average Cost for Two:** ₹555.43.
* **Online Ordering Impact:** Over 54% of restaurants offer online delivery, driving higher customer vote engagement.
